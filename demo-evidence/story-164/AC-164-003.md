## (a) Behavioral Gate Demos — Three Crafted Diffs

### Test 1: Real content (PASS + count)

Diff adds three lines under `## [Unreleased]`: a `### Added` subheading and two bullet lines:

```
$ printf 'diff --git a/CHANGELOG.md b/CHANGELOG.md\n--- a/CHANGELOG.md\n+++ b/CHANGELOG.md\n@@ -1,4 +1,7 @@\n ## [Unreleased]\n+\n+### Added\n+- feat: citation preflight validator (AC-164-002)\n+- chore: changelog-gate content assertion (AC-164-003)\n \n ## [0.12.0]\n' | \
    bash bin/changelog-gate-check
PASS: CHANGELOG.md updated with 2 content line(s).

$ echo $?
0
```

Content line count = 2 — from the two bullet lines only. `grep -v '^+##'` is a prefix
match: it removes any added line whose text begins with `+##`, which includes `+###`, `+####`,
and all deeper heading levels. The `+### Added` line is therefore also filtered. Only the
two bullet lines (`+- feat:` and `+- chore:`) survive all four greps and are counted.

### Test 2: Whitespace-only (FAIL)

Diff adds only blank/whitespace lines:

```
$ printf 'diff --git a/CHANGELOG.md b/CHANGELOG.md\n--- a/CHANGELOG.md\n+++ b/CHANGELOG.md\n@@ -1,3 +1,5 @@\n ## [Unreleased]\n+\n+   \n \n' | \
    bash bin/changelog-gate-check
FAIL: CHANGELOG.md touched but no content added to [Unreleased] section.
(A whitespace-only touch does not satisfy AC-158-001 / PG-W71-CHANGELOG.)

$ echo $?
1
```

`grep -v '^+[[:space:]]*$'` filters the blank and whitespace-only added lines.
`{ ... || true; }` brace group prevents `set -euo pipefail` from aborting on empty
selection (EC-004). CONTENT_LINES=0 → FAIL branch reached.

### Test 3: Header-only (FAIL)

Diff adds only `##`-prefixed section/version heading lines:

```
$ printf 'diff --git a/CHANGELOG.md b/CHANGELOG.md\n--- a/CHANGELOG.md\n+++ b/CHANGELOG.md\n@@ -0,0 +1,2 @@\n+## [Unreleased]\n+## [0.13.0]\n' | \
    bash bin/changelog-gate-check
FAIL: CHANGELOG.md touched but no content added to [Unreleased] section.
(A whitespace-only touch does not satisfy AC-158-001 / PG-W71-CHANGELOG.)

$ echo $?
1
```

`grep -v '^+##'` filters both `## [Unreleased]` and `## [0.13.0]` heading lines (EC-003,
F-S164P7-002). CONTENT_LINES=0 → FAIL branch reached.
