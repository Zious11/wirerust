### MALFORMED (no file:line format)

```
$ echo "some file without colon separator" | \
    WIRERUST_REPO_ROOT=$REPO_ROOT python3 bin/validate-citations
MALFORMED: some file without colon separator
FAIL: 1 of 1 citations invalid

$ echo $?
1
```

Note denominator: MALFORMED counts in both K (failures) and N (total), so single
malformed input → `FAIL: 1 of 1` not `FAIL: 1 of 0` (F-S164P2-002).

### OUTSIDE REPO (absolute path — CWE-22)

```
$ echo "/etc/passwd:1" | \
    WIRERUST_REPO_ROOT=$REPO_ROOT python3 bin/validate-citations
OUTSIDE REPO: /etc/passwd
FAIL: 1 of 1 citations invalid

$ echo $?
1
```

Rejected via `resolve()+is_relative_to()` before file-existence check (F-S164P2-003).

### NOT A FILE (citation to a directory)

```
$ echo ".factory/maintenance:1" | \
    WIRERUST_REPO_ROOT=$REPO_ROOT python3 bin/validate-citations
NOT A FILE: .factory/maintenance
FAIL: 1 of 1 citations invalid

$ echo $?
1
```

Path exists and passes `exists()` but fails `is_file()` check (F-S164P8-001).

### UNREADABLE (chmod 000 citations file — exit 2 usage error)

```
$ TMPFILE=$(mktemp)
$ echo "CLAUDE.md:1" > "$TMPFILE"
$ chmod 000 "$TMPFILE"
$ WIRERUST_REPO_ROOT=$REPO_ROOT python3 bin/validate-citations "$TMPFILE" 2>&1
Error: cannot read citations file: /tmp/tmp.XXXXXXXX: [Errno 13] Permission denied: '/tmp/tmp.XXXXXXXX'

$ echo $?
2
```

Not running as root (root can bypass chmod 000, which would produce false pass — this
matches the T19/T22 root-skip guard pattern in the self-test suite).
