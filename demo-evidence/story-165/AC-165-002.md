## Broadened Two-Item Mandate (F-S165P4-002)

The mandate was broadened from a per-test-only mandate to a two-item obligation:

1. **Per-test row-verify** (when per-test rows are present): row-verify at least three
   randomly-selected entries from any per-test results table by reading the source file
   to confirm each test function name exists at the implied location.

2. **Aggregate-count cross-check** (when aggregate counts are claimed): cross-check every
   claimed aggregate count or result (e.g., "22 passed", "101/101", "22 + 10 = 32") against
   actual test-run or CI output. A count that cannot be matched to actual run output is a
   blocking review finding.

F-S165P4-002 is recorded in the Correction Record at line 158 of the mandate doc. The
wave-74 root defect (F-W74G-P3-001) was an aggregate-count row ("python 101/101" / "22+10=32")
computed before the final 10-test suite was complete and not matching actual CI output.
