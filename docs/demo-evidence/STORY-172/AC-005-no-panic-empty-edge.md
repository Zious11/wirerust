## Empty-Slice Behavior

When `on_data` receives `data = &[]`, the carry is prepended (carry remains unchanged if
already empty), producing an empty window for the frame-walk loop. The loop condition
checks that at least 1 byte is available; finding zero bytes, it returns immediately. No
cursor arithmetic is performed on a zero-length slice — no off-by-one or out-of-bounds
access is possible.
