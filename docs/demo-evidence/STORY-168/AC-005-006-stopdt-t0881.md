## Success-Path and Error-Path Demonstration

### AC-168-005: STOPDT-act While Session Active → T0881 Possible (BC-2.19.011)

```
Precondition:  state.session_started == true   (STARTDT observed on this flow)
Input:         CF1=0x13 (STOPDT-act; bits1:0=0b11 → UFormat)
Call:          process_u_frame(&mut state, 0x13)

Postcondition: state.session_started == false

Finding emitted:
  category:          ThreatCategory::Impact
  verdict:           Verdict::Possible
  confidence:        Confidence::Medium
  mitre_techniques:  ["T0881"]
  summary:           "IEC-104 STOPDT-act received: CF1=0x13 — ICS data-transfer service stop
                      request observed (T0881 inhibit-response-function; BC-2.19.011/012)"
  evidence:          ["CF1=0x13 (STOPDT-act)"]
```

Interpretation: STOPDT observed on a session-active flow is plausibly normal IEC-104 behavior
(controlled shutdown); confidence Possible reflects routine operational context.

### AC-168-006: STOPDT-act Without Prior STARTDT → T0881 Likely (BC-2.19.012)

```
Precondition:  state.session_started == false  (no STARTDT seen; cold-start)
Input:         CF1=0x13 (STOPDT-act)
Call:          process_u_frame(&mut state, 0x13)

Postcondition: state.session_started == false  (unchanged; was already false)

Finding emitted:
  category:          ThreatCategory::Impact
  verdict:           Verdict::Likely
  confidence:        Confidence::Medium
  mitre_techniques:  ["T0881"]
  summary:           "IEC-104 STOPDT-act received: CF1=0x13 — ICS data-transfer service stop
                      request observed (T0881 inhibit-response-function; BC-2.19.011/012)"
  evidence:          ["CF1=0x13 (STOPDT-act)",
                      "STOPDT received without prior STARTDT on this flow"]
```

Interpretation: STOPDT without a prior STARTDT is anomalous — no session lifecycle evidence
for the flow. Confidence escalates to Likely (stronger than Possible). BC-2.19.012 postcondition 3
mandates the "without prior STARTDT" note in evidence so analysts can identify cold-start stops
without correlating the session timeline themselves.

### Confidence Escalation Invariant (BC-2.19.012 invariant 1)

| STOPDT Context | `session_started` prior | Verdict | Evidence note |
|----------------|------------------------|---------|---------------|
| After STARTDT | `true` | `Possible` | `"CF1=0x13 (STOPDT-act)"` |
| Without STARTDT | `false` | `Likely` | `"CF1=0x13 (STOPDT-act)"` + `"STOPDT received without prior STARTDT on this flow"` |

`Possible != Likely` — the distinction is verified in `test_BC_2_19_012_invariant_stopdt_confidence_escalation_likely_vs_possible`.

### STOPDT-con (CF1=0x23): No Finding (ACT-only MVP)

```
Precondition:  state.session_started == true
Input:         CF1=0x23 (STOPDT-con; RTU confirms deactivation)
Call:          process_u_frame(&mut state, 0x23)

Postcondition: state.session_started == false
Finding:       None
```

STOPDT-con is ACT-only MVP per ADR-013 Decision 5. The RTU confirmation sets session state
but does not emit T0881 — only the initiating STOPDT-act is the anomaly trigger.
